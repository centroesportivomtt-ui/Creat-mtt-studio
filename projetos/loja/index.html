Como funciona

Do .zip ao primeiro pedido em poucos minutos

  1. Copie a pasta

    Descompacte e copie .claude/ para a raiz do seu repositório. O README mostra como juntar com agentes que você já tenha.

  2. Peça pelo nome

    No Claude Code, escreva por exemplo: Use o agente frontend para construir a página de preços. Para um projeto inteiro, chame o fluxo agencia com o briefing.

    Cada etapa deixa um RELATORIO.md. Abra a sede para ver quem está trabalhando e leia o que o revisor e o QA apontaram antes de publicar.

Antes de comprar

Perguntas diretas, respostas diretas

Preciso de alguma assinatura?

Sim. Os agentes rodam dentro do Claude Code, então você precisa de uma assinatura ou conta do Claude Code ativa. O pacote não inclui acesso ao Claude. Para a sede e os prints também é preciso ter Node.js e o Playwright, e o README mostra os comandos.

Quanto custa usar no dia a dia?

O pacote é pago uma vez. Os tokens que cada agente consome são cobrados na sua conta do Claude Code, por sua conta. Um fluxo com muitos agentes gasta mais do que um pedido único; o guia mostra como acompanhar o consumo e quando chamar só um agente.

Isso vai me fazer ganhar dinheiro?

Não prometemos nenhum ganho financeiro. É uma ferramenta de trabalho: organiza o Claude Code em especialistas com revisão e teste no meio. O resultado depende do que você constrói e de como usa.

É um produto oficial da Anthropic?

Não. "Para Claude Code" indica compatibilidade. A Creat Nuvem é independente e não tem vínculo, patrocínio ou aprovação da Anthropic. Claude e Claude Code são marcas da Anthropic.

Posso usar em projetos de clientes? E revender?

Pode usar em projetos pessoais, comerciais e de clientes. Não pode revender, redistribuir nem publicar o pacote, nem partes dele como produto próprio. O Lite tem licença MIT.
