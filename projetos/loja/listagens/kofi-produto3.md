## Short description

A one-page barbershop site: pick a time, confirm, and the booking opens in WhatsApp.

## Long description

A single-page website for a barbershop, ready to customize and publish for free. Visitors pick a day and time, see only the services that fit before the next booked slot or closing time, enter their name and WhatsApp number, and confirm. The site then opens WhatsApp with a ready-made message to the shop: service, barber, day, time and price.

**What's in the zip**

- The full site in plain HTML, CSS and JavaScript. No build step, nothing to install. Double-click `index.html` to open it.
- `config.js`: the only file you edit to change the shop name, WhatsApp number, address, Instagram, opening hours, services with price and duration, team, reviews and the four brand colors.
- An opening ritual: visitors sharpen a razor on a leather strop with a finger or the mouse, and the booking is confirmed with the same gesture. A regular button and keyboard controls are always available.
- A live status sign ("Open now" or the next opening time).
- Sound effects synthesized in the browser, with a mute button. No audio files.
- `README.md` with every config field explained and free hosting steps.

**Language note:** all site text and the README are in Brazilian Portuguese, and the phone format assumes Brazil. The visible text is filled in from `config.js` when the page opens, so translating it means editing one file.

**Limits, stated plainly**

- There is no server or admin panel. Bookings arrive as WhatsApp messages; the shop manages the schedule by replying.
- One customer cannot see slots booked by another. A slot only shows as taken on the device that booked it.
- Free hosting depends on each provider's current rules. A custom domain costs extra.
